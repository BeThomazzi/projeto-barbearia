# 💈 Projeto Barbearia

> 🇧🇷 Landing page desenvolvida para uma barbearia, utilizando HTML5 e SCSS, com foco em uma apresentação visual simples, moderna e responsiva.

---

## 🌐 Sobre o projeto

O **Projeto Barbearia** é uma landing page desenvolvida como um projeto prático de frontend, utilizando **HTML5 e SCSS**.

A proposta foi criar uma página simples e objetiva para apresentar uma barbearia, seus serviços e informações principais, utilizando uma estrutura visual voltada para negócios locais.

O projeto faz parte de uma etapa inicial de desenvolvimento frontend, com foco na construção de páginas estáticas, organização de estilos e aplicação de conceitos fundamentais de HTML e CSS.

### ✨ Principais características

* Landing page para barbearia
* Layout responsivo
* Estrutura semântica em HTML5
* Estilização utilizando SCSS
* Organização de estilos por componentes/seções
* Seções informativas sobre o estabelecimento
* Apresentação de serviços
* Design adaptado para diferentes tamanhos de tela
* Interface simples e objetiva

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/BeThomazzi/projeto-barbearia.git
```

Entre na pasta:

```bash
cd projeto-barbearia
```

Como o projeto utiliza apenas HTML e SCSS, a página pode ser aberta diretamente no navegador após a compilação do SCSS.

Caso utilize o Sass CLI, a compilação pode ser realizada com:

```bash
sass scss/style.scss css/style.css
```

Para acompanhar alterações durante o desenvolvimento:

```bash
sass --watch scss/style.scss css/style.css
```

Depois, basta abrir o arquivo `index.html` no navegador.
